Section (v) Rubric
01
Binary Syllabic Independence

In metrical abstraction, syllables are classified into the discrete binary field {0, 1} (Laghu/Guru). While real speech has continuous pitch and duration variations, Indian prosody proved that discrete abstraction enables combinatorial analysis.

02
Combinatorial Visual Rendering Limits

While the mathematical engine evaluates ranks up to n = 64 using arbitrary precision integers in O(n) time, rendering all 2^n visual rows in the browser DOM is capped at n = 8 to prevent memory exhaustion.

03
Poetic License & Sandhi Ambiguities

Classical Sanskrit scansion allows padānta-laghu-guru-vyavasthā (verse-final syllable optionally considered Guru). Our engine provides a dynamic toggle for this phonological rule.

04
Historical Precedence over Western Formulations

Piṅgala's binary system preceded Gottfried Leibniz (1679 CE) by over 1,900 years, and Halāyudha's Meru-Prastāra preceded Blaise Pascal (1654 CE) by over 700 years.

DK

"The first known description of binary numbers was by the Indian scholar Pingala (c. 200 BC)... He formulated the rules for prastāra, naṣṭam, and uddiṣṭam, which provide conversions between permutations and their ordinal positions."

IKS to Computer Science Conceptual Mapping

This project formally addresses Section (b) of the IKS in Computational Systems course rubric: Piṅgala's Chandaḥśāstra as Binary Encoding and Combinatorial Generation.

IKS Metrical Concept (*Chandaḥśāstra*) Computer Science / Discrete Math Concept Mathematical Formalism Computational Implementation
Laghu (लघु) (Short Syllable) Binary Digit `0` $b_i = 0$, weight = 1 mora Bit 0, 880 Hz crisp sine pulse (100ms)
Guru (गुरु) (Long Syllable) Binary Digit `1` $b_i = 1$, weight = 2 morae Bit 1, 440 Hz resonant tone (220ms)
Akṣara-Gaṇa (गण) 3-bit Octal Triplet ($2^3 = 8$) $\{Ya, Ma, Ta, Ra, Ja, Bha, Na, Sa\}$ Octal lookup dictionary, 8 state gaṇas
Prastāra (प्रस्तार) Truth Table / Permutation Generation $S_n = \{0, 1\}^n, |S_n| = 2^n$ Lexicographical matrix generator
Naṣṭam (नष्टम्) Decimal-to-Binary Rank Decoder $f^{-1}: \mathbb{Z}_{\ge 1} \to \{0,1\}^n$ Modulo-2 halving division algorithm
Uddiṣṭam (उद्दिष्टम्) Binary-to-Decimal Rank Encoder $R = 1 + \sum b_i 2^{i-1}$ Horner's positional place accumulator
Saṅkhyā (संख्या) Divide & Conquer Fast Exponentiation $O(\log n)$ Exponentiation dvir ardhe recursive power function
Meru-Prastāra (मेरुप्रस्तार) Binomial Dynamic Programming $C(n,k) = C(n-1,k-1) + C(n-1,k)$ 2D memoization pyramid (Pascal's triangle)
Mātrā-Prastāra (मात्राप्रस्तार) Integer Compositions (Fibonacci) $F(m) = F(m-1) + F(m-2)$ Virahāṅka-Hemachandra composition engine
